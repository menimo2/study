# לוגיקת ייצור — תיעוד אירוע

[[דוח תיעוד אירוע|← חזרה לדוח]] · [[תבנית פלט של תיעוד אירוע]]

לחיצה על `צור תיעוד` מרכיבה את המסמך מהטופס.  
שדה ריק או checkbox לא מסומן — לא מייצרים עבורו שורה.

## אנונימיזציה

```
nameDisplay = "***"
```

שם אמיתי לא נכנס לפלט, גם אם מולא בטופס.

## ברירות מחדל אם ריק

| שדה | אם ריק |
|---|---|
| `studentClass` | `---` |
| `place` | `---` |
| תאריך ושעה יחד | `---` |
| `present` | לא מדפיסים את שורת הנוכחים |
| אין אף סוג | לא מדפיסים «סוג האירוע» |
| `description` | לא מדפיסים את פרק התיאור |
| אין אף החלטה | לא מדפיסים «החלטות שהתקבלו» |

## מגדר

כותרת השם: `שם התלמיד` / `שם התלמידה`.  
לכל checkbox: `text_m` או `text_f`.

## תאריך

ערך שדה `date` מודפס כ-`DD.MM.YYYY`.

שורת הזמן:

| מילוי | טקסט |
|---|---|
| תאריך ושעה | `{תאריך}, {שעה}` |
| רק תאריך | `{תאריך}` |
| רק שעה | `{שעה}` |
| שניהם ריקים | `---` |

## הרכבה

1. כותרת: `תיעוד אירוע`
2. `{שם התלמיד / שם התלמידה}: *** | כיתה: {כיתה}`
3. `מקום: {מקום} | זמן: {זמן}`
4. אם יש נוכחים: `נוכחים: {נוכחים}`
5. שורה ריקה
6. אם יש סוגים: `סוג האירוע: {רשימה}.`
7. שורה ריקה, ואם יש תיאור:

```
תיאור האירוע:
{תיאור}
```

8. שורה ריקה, ואם יש החלטות:

```
החלטות שהתקבלו:
• {החלטה}
• {החלטה}
```

חיבור סוגי האירוע: נקודה-פסיק + רווח (`; `).  
החלטות: שורה לכל החלטה, עם `• `.

`type_other` ו-`dec_suspend` ו-`dec_other` מורכבים לפי [[סוג ותיאור של תיעוד אירוע]] ו-[[החלטות של תיעוד אירוע]].

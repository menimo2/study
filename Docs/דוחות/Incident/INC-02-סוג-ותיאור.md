# סוג האירוע ותיאור — תיעוד אירוע

[[דוח תיעוד אירוע|← חזרה לדוח]]

בממשק מציגים שלוש קבוצות, בלי לשנות את סדר הפלט:

1. אלימות ופגיעה — חמשת הראשונים + השחתת רכוש
2. גבולות — חמשת סעיפי הגבולות וההטרדה
3. במסגרת — מהקשבה לצוות ועד טלפון, ואז אירוע אחר

## `incidentOther`

| | |
|---|---|
| סוג | `textarea` |
| תווית | פירוט האירוע האחר |
| חובה | לא |
| אנונימי | לא |
| מוצג | רק כש-`type_other` מסומן |

אם `type_other` מסומן ויש טקסט: בפלט `אירוע אחר: {טקסט}` במקום המילים «אירוע אחר» לבדן.  
אם מסומן ואין טקסט: `אירוע אחר`.

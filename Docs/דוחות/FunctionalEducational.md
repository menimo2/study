# דוח חינוכי-תפקודי

[[קטלוג דוחות|← קטלוג דוחות]] · [[README|בית]]

מחולל דוח שמסייע לצוות חינוכי לנסח דוח תפקודי על תלמיד/ה: רקע ואבחנות, למידה, רגש-התנהגות, חברה, והמלצות.

| | |
|---|---|
| מזהה | `functional-educational` |
| כותרת בממשק | מחולל דו"ח חינוכי-תפקודי חכם |
| תת-כותרת | ניסוח אישי ומותאם מגדרית באופן אוטומטי (אנונימי) |
| קהל | מורות/ים, יועצות, צוות חינוך מיוחד |
| שפה | עברית, RTL |
| אב-טיפוס קיים | `FunctionalEducational.html` (תוצר ישן — לא מקור האמת) |

## מפת הדף

```
דוח חינוכי-תפקודי
├── ממשק
├── לוגיקת ייצור
├── תבנית פלט
└── שדות
    ├── 1. פרטים אישיים ורקע היכרות
    ├── 2. רקע חינוכי, אבחנתי וסל תמיכות
    ├── 3. תחום לימודי ותפקודי לומד
    ├── 4. תחום התנהגותי-רגשי
    ├── 5. תחום חברתי ותקשורתי
    └── 6. סיכום והמלצות הצוות
```

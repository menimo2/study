# תיעוד אירוע

[[קטלוג דוחות|← קטלוג דוחות]] · [[README|בית]]

מחולל תיעוד קצר לאירוע בבית הספר: מה קרה, איפה ומתי, ומה הוחלט.

| | |
|---|---|
| מזהה | `incident` |
| כותרת בממשק | תיעוד אירוע |
| תת-כותרת | מסמנים את סוג האירוע ואת ההחלטות — והתיעוד מתמלא (אנונימי) |
| קהל | מחנכות, יועצות, הנהלה |
| שפה | עברית, RTL |
| מצב | ניסוי — אב-טיפוס HTML |
| אב-טיפוס | `Incident.html` |

## זרימה

```
פרטי האירוע
  └── סוג האירוע (אפשר כמה)
        └── תיאור
              └── החלטות
                    └── צור תיעוד
```

אפשר לסמן כמה סוגי אירוע וכמה החלטות.  
«אירוע אחר» ו«אחר» פותחים מלל חופשי. «השעייה» פותחת מתאריך ועד תאריך.

# ניתוח קריאה וכתיבה

[[קטלוג דוחות|← קטלוג דוחות]] · [[README|בית]]

מחולל קצר: המורה בוחרת מה בדקה, מסמנת מה ראתה, ומקבלת כמה שורות ניתוח.

לא ציון כמותי ולא אחוזונים — רק מאפיינים איכותיים.

| | |
|---|---|
| מזהה | `literacy` |
| כותרת בממשק | מחולל ניתוח קריאה וכתיבה |
| תת-כותרת | מסמנים מה שרואים בקריאה / בהכתבה — והניתוח מתמלא (אנונימי) |
| קהל | מחנכות, מורות שפה, צוות חינוך מיוחד |
| שפה | עברית, RTL |
| מצב | ניסוי — אב-טיפוס HTML |
| אב-טיפוס | `Literacy.html` |
| פלט | כ־5 שורות |

## זרימה

```
פרטים
  └── סוג בדיקה: קריאת מילים / קריאת טקסט / הכתבה
        └── סימון מאפיינים (checkbox)
              └── צור ניתוח
```

המורה בוחרת **סוג בדיקה אחד**. רק המאפיינים של הסוג הזה מוצגים.

אין כתיבת מלל — רק בחירה וסימון.

## מה נכנס לפלט

תמיד מודפס משפט הפתיחה:

`התלמיד/ה {הינו / הינה} {תלמיד / תלמידה} המפגין/ה חוזקות לצד קשיים בתפקוד היומיומי במסגרת.`

אחר כך:

- אם `recommendations` מולא — מצרפים את הטקסט כמו שהוא.
- אם ריק — מצרפים:
  `הצוות החינוכי ממשיך ללוות את התלמיד/ה תוך התאמת המענים הנדרשים {לקידומו / לקידומה}.`

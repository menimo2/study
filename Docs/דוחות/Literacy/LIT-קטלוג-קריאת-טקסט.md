# קטלוג — קריאת טקסט

[[קטלוג ניתוח קריאה וכתיבה|← קטלוג]]

סוג בדיקה: `text_reading`

קריאה בקול של משפטים או קטע. כולל גם אופן הקריאה וגם שיבושים בהקשר.

## אופן הקריאה — checkbox

| id | תווית בממשק | text_m | text_f |
|---|---|---|---|
| `text_manner_blend` | קורא בהברות | קורא בהברות, הברה אחר הברה | קוראת בהברות, הברה אחר הברה |
| `text_manner_inacc_slow` | לא מדויק ואיטי | קורא לאט ובאי-דיוק | קוראת לאט ובאי-דיוק |
| `text_manner_acc_slow` | מדויק ואיטי | קורא במדויק אך לאט | קוראת במדויק אך לאט |
| `text_manner_inacc_fast` | לא מדויק ומהיר | קורא במהירות אך באי-דיוק | קוראת במהירות אך באי-דיוק |
| `text_manner_punct` | מתייחס לפיסוק | חותך משפטים לפי סימני הפיסוק | חותכת משפטים לפי סימני הפיסוק |
| `text_manner_punct_miss` | מתעלם מפיסוק | אינו חותך משפטים לפי סימני הפיסוק | אינה חותכת משפטים לפי סימני הפיסוק |
| `text_manner_prosody` | הנגנה מותאמת | מנגן את הקריאה בהתאם לתוכן ולפיסוק | מנגנת את הקריאה בהתאם לתוכן ולפיסוק |
| `text_manner_self_correct` | מתקן שגיאות בעצמו | מבחין בשגיאות ומתקן אותן בעצמו | מבחינה בשגיאות ומתקנת אותן בעצמה |

`punct` ו-`punct_miss` לא אמורים להיות מסומנים יחד.

## שיבושים בטקסט — checkbox

| id | תווית בממשק | text_m | text_f |
|---|---|---|---|
| `text_err_sub_ok` | מחליף מילה בלי לשנות תוכן | מחליף מילים במילים משמעותיות שאינן משנות את תוכן הטקסט | מחליפה מילים במילים משמעותיות שאינן משנות את תוכן הטקסט |
| `text_err_sub_bad` | מחליף מילה ומשנה תוכן | מחליף מילים במילים משמעותיות שמשנות את תוכן הטקסט | מחליפה מילים במילים משמעותיות שמשנות את תוכן הטקסט |
| `text_err_nonword` | קורא מילה שאינה בעברית | מחליף מילים ברצף צלילים שאינו מילה בעברית | מחליפה מילים ברצף צלילים שאינו מילה בעברית |
| `text_err_letters` | מחליף / משמיט / מוסיף אותיות | מחליף, משמיט, מוסיף או משנה סדר של עיצורים ותנועות | מחליפה, משמיטה, מוסיפה או משנה סדר של עיצורים ותנועות |
| `text_err_affix` | שורש נכון, מוספית משובשת | מזהה את שורש המילה אך משבש תחיליות, סופיות או אותיות שימוש | מזהה את שורש המילה אך משבשת תחיליות, סופיות או אותיות שימוש |
| `text_err_function` | משבש מילות תפקוד | מחליף או משמיט מילות קישור, יחס או כינויים | מחליפה או משמיטה מילות קישור, יחס או כינויים |

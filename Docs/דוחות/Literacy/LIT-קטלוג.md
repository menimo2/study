# קטלוג ניתוח קריאה וכתיבה

[[דוח ניתוח קריאה וכתיבה|← חזרה לדוח]] · [[מקורות קטלוג ניתוח קריאה וכתיבה]]

כאן יושב **כל המלל**. המורה מסמנת; הקוד רק מציג ומרכיב.

## עץ

```
סוג בדיקה
  └── קבוצה (אופן קריאה / שיבושים / שלב / כתב)
        └── מאפיין (checkbox או בחירה אחת)
```

כל מאפיין (checkbox): `id` + תווית בממשק + `text_m` / `text_f`.  
שלב פענוח / שלב כתיב: `select` עם אותם ניסוחי מגדר לכל ערך.

פירוט מה נשמר בטופס: [[מאפיינים של ניתוח קריאה וכתיבה]].

## חוזה סימון

- `checkbox` לא מסומן — לא נכנס לפלט.
- אפשר לסמן כמה מאפיינים באותה קבוצה, **חוץ מקבוצת שלב** — שם בחירה אחת.
- שינוי מין מעדכן תצוגה מקדימה וגם את הפלט.

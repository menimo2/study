# ממשק — ניתוח קריאה וכתיבה

[[דוח ניתוח קריאה וכתיבה|← חזרה לדוח]] · [[תשתית]]

אותה שפה עיצובית כמו [[ממשק של דוח חינוכי-תפקודי]]: RTL, `#2c3e50` / `#3498db`, כרטיסיות, רוחב `950px`.

אין מקרא ירוק/אדום. הסימון הוא checkbox.

## מבנה העמוד

1. כותרת: `מחולל ניתוח קריאה וכתיבה`
2. משפט: `מסמנים מה שרואים בקריאה / בהכתבה — והניתוח מתמלא (אנונימי)`
3. כרטיסייה: פרטים (כולל סוג הבדיקה)
4. כרטיסייה: מאפיינים — משתנה לפי `taskType`
5. כפתור `צור ניתוח`
6. אזור פלט — **מוסתר** עד ליצירה

## כרטיסיית המאפיינים

לפי סוג הבדיקה מציגים רק את הקבוצות הרלוונטיות מ[[קטלוג ניתוח קריאה וכתיבה]].

כל קבוצה: תת-כותרת + רשימת checkbox (או בחירה אחת לשלב).

כש-checkbox מסומן — מתחת לתווית מופיע משפט הפלט, לפי המין שנבחר.  
שינוי המין מעדכן מיד את כל התצוגות המקדימות.

## אזור הפלט

מופיע רק אחרי `צור ניתוח`.

- כותרת: `הניתוח המוכן (מוסתר פרטים מזהים)`
- תיבת טקסט (`white-space: pre-wrap`) עם הפלט
- כפתור `העתק` — מעתיק ללוח. הודעת הצלחה: `הניתוח הועתק בהצלחה! תוכלי להדביק אותו (Ctrl+V) בקובץ Word.`

אחרי יצירה — גלילה חלקה לאזור הפלט.

## ברירות מחדל

- `studentGender` = `male`
- `taskType` = `word_reading`
- כל ה-checkbox = `false`
- `wordStage` / `dictStage` = ריק

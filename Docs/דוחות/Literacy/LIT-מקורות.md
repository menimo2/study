# מקורות — ניתוח קריאה וכתיבה

[[קטלוג ניתוח קריאה וכתיבה|← קטלוג]] · [[דוח ניתוח קריאה וכתיבה]]

## מה לקחנו ומה לא

מתוך חוברת הערכה איכותית של תהליכי קריאה וכתיבה (טבלאות 5–8):

- **לקחנו את המבנה:** שלושה סוגי בדיקה (קריאת מילים, קריאת טקסט, הכתבה), וחלוקה לאופן קריאה / שיבושי פענוח / סוגי שגיאות כתיב / שלב התפתחותי / איכות גרפית.
- **לא העתקנו** טבלאות, דוגמאות מילים, או ניסוח מקורי של החוברת.
- **המלל שלנו** נכתב מחדש: תווית קצרה למורה + משפט פלט לפי מין.

הדירוג המקורי (חמש דרגות / גבוה-ממוצע-נמוך) הומר ל-**checkbox**: מסומן = נצפה, לא מסומן = לא נכנס לדוח.

# לוגיקת ייצור — ניתוח קריאה וכתיבה

[[דוח ניתוח קריאה וכתיבה|← חזרה לדוח]] · [[תבנית פלט של ניתוח קריאה וכתיבה]]

לחיצה על `צור ניתוח` מרכיבה טקסט קצר מהטופס.  
רק מאפיינים מסומנים נכנסים. קבוצה ריקה — מדלגים על השורה.

## אנונימיזציה

```
nameDisplay = "***"
```

שם אמיתי לא נכנס לפלט.

## ברירות מחדל אם ריק

| שדה | אם ריק |
|---|---|
| `studentClass` | `---` |
| `taskType` | אין פלט עד שנבחר סוג בדיקה |

## מגדר

המעטפת לפי מין (`שם התלמיד` / `שם התלמידה`).  
לכל checkbox מסומן: `text_m` או `text_f` מהקטלוג.  
לשלב שנבחר: אותו כלל.

תווית סוג הבדיקה בפלט:

| ערך | בפלט |
|---|---|
| `word_reading` | קריאת מילים |
| `text_reading` | קריאת טקסט |
| `dictation` | הכתבה |

## הרכבה

סדר השורות:

1. כותרת: `ניתוח קריאה וכתיבה — {סוג בדיקה}`
2. פרטים אנונימיים
3. שלב (רק אם נבחר) — משפט אחד
4. אופן הקריאה — אם יש לפחות checkbox אחד:  
   `אופן הקריאה: {text join "; "}.`
5. שיבושים / שגיאות — אם יש לפחות אחד:  
   `שיבושים שנצפו: {text join "; "}.`  
   בהכתבה מפצלים רק אם רוצים קיצור: מחברים פונטיות + מורפולוגיות + אחרות לאותה שורה.
6. כתב גרפי (הכתבה בלבד) — אם יש לפחות אחד:  
   `בכתב: {text join "; "}.`

חיבור פריטים: נקודה-פסיק + רווח (`; `).

## מה לא נכנס

- checkbox לא מסומן
- שם התלמיד/ה
- קבוצה בלי אף סימון

# תבנית פלט — ניתוח קריאה וכתיבה

[[דוח ניתוח קריאה וכתיבה|← חזרה לדוח]] · [[לוגיקת ייצור של ניתוח קריאה וכתיבה]]

טקסט קצר להעתקה ל-Word. שורה בלי ערכים — לא מודפסת.

```
ניתוח קריאה וכתיבה — {קריאת מילים / קריאת טקסט / הכתבה}
{שם התלמיד / שם התלמידה}: *** | כיתה: {כיתה}

{משפט שלב, אם נבחר}.
אופן הקריאה: {מאפיינים שסומנו}.
שיבושים שנצפו: {מאפיינים שסומנו}.
בכתב: {מאפייני כתב שסומנו, הכתבה בלבד}.
```

## דוגמה (זכר, קריאת מילים)

```
ניתוח קריאה וכתיבה — קריאת מילים
שם התלמיד: *** | כיתה: ב'2

מפענח את המילה במלואה, במאמץ ובקצב איטי.
אופן הקריאה: קורא בהברות, הברה אחר הברה; קורא במדויק אך לאט.
שיבושים שנצפו: מחליף עיצורים או תנועות (בדמיון צורה או צליל); משמיט אותיות או הברות מתוך המילה.
```

## דוגמה (נקבה, הכתבה)

```
ניתוח קריאה וכתיבה — הכתבה
שם התלמידה: *** | כיתה: ג'1

מייצגת את כל צלילי המילה, לא תמיד באות המוסכמת.
שיבושים שנצפו: מחליפה אותיות שמייצגות צלילים דומים; טועה באותיות שוות-צליל במוספיות.
בכתב: גודל האותיות אינו אחיד; הרווח בין המילים אינו מאפשר להבחין בין מילה למילה.
```

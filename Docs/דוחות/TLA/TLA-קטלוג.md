# קטלוג תל"א

[[דוח תל"א|← חזרה לדוח]] · [[איך להוסיף יעד לתל"א]]

כאן יושב **כל המלל**. הוספת יעד = הוספה לקובץ התחום, לא שינוי קוד.

## עץ

```
תחום
  └── מטרה          (id + text_m / text_f)
        └── יעד     (id + text_m / text_f + evaluation_m / evaluation_f)
              └── דרכים  (כל דרך: id + text_m / text_f)
```

כל יעד שייך למטרה אחת.  
כל דרך שייכת ליעד אחד. אם אותה פעולה מתאימה לשני יעדים — מעתיקים אותה לשני המקומות (כדי שהמורה תראה רק מה שרלוונטי).

## מזהים

- באנגלית, קבועים, לא משנים אחרי שיש דוחות.
- מתחילים בתחום: `social_…`, `academic_…`, `emotional_…`, `behavioral_…`
- יעד: `{מזהה_מטרה}_{שם_קצר}`
- דרך: `{מזהה_יעד}_{שם_קצר}`

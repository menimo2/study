# איך להוסיף יעד לתל"א

[[קטלוג תל"א|← קטלוג]] · [[דוח תל"א]]

כדי שהמורה תוכל לבחור יעד חדש, מוסיפים אותו **תחת המטרה המתאימה** בקובץ התחום.

## שלבים

1. פותחים את קובץ התחום: [[קטלוג תל"א — חברתי]] / [[קטלוג תל"א — לימודי]] / [[קטלוג תל"א — רגשי]] / [[קטלוג תל"א — התנהגותי]]
2. מוצאים את המטרה. אם אין מטרה מתאימה — מוסיפים קודם בלוק מטרה חדש.
3. מדביקים בלוק יעד עם הדרכים שלו (התבנית למטה).
4. בודקים שה-`id` לא קיים כבר.
5. אם המורה אמורה **להגיע ליעד מתצפית כיתה** — מוסיפים שורה ב[[תצפיות כיתה של תל"א]] (או מצמידים את ה-`id` של היעד לתצפית קיימת).

אין צורך לגעת בממשק. אחרי שהקטלוג והתצפיות מתמלאים, הכלי קורא אותם.

## תבנית מטרה חדשה

```markdown
### `social_example_goal`
- תווית קצרה בממשק: יוזמה בהפסקה
- text_m: …
- text_f: …
```

## תבנית יעד חדש (עם דרכים)

מדביקים **מתחת** למטרה:

```markdown
#### `social_example_goal_invite`
- text_m: …
- text_f: …
- evaluation_m: …
- evaluation_f: …

דרכים של היעד הזה:

| id | text_m | text_f |
|---|---|---|
| `social_example_goal_invite_practice` | … | … |
| `social_example_goal_invite_pair` | … | … |
```

## מה לכתוב בכל שדה

| שדה | תפקיד |
|---|---|
| תווית קצרה | מה שהמורה רואה ברשימה (לא חייב להיות משפט מלא) |
| `text_m` / `text_f` | המשפט שנכנס לדוח |
| `evaluation_*` | איך נדע שהתקדמנו — מילולי |
| דרכים | רק פעולות שקשורות **ליעד הזה** |

אם יעד בלי דרכים — המורה תוכל לבחור את היעד, ובדוח לא תופיע שורת דרכים.

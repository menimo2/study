# מטרות ויעדים — תל"א

[[דוח תל"א|← חזרה לדוח]] · [[תצפיות כיתה של תל"א]] · [[קטלוג תל"א]] · [[איך להוסיף יעד לתל"א]]

המורה **מסמנת תצפיות**. היא לא ממציאה ניסוח ולא בוחרת תחום.

המלל כולו חי בקטלוג (MD). המיפוי חי ב[[תצפיות כיתה של תל"א]]. הקוד רק מציג וממלא.

## מה המורה עושה

```
1. מסמנת מה היא רואה בכיתה (אפשר כמה)
2. לוחצת «מלא תל"א» — המערכת ממפה ליעדים, מצרפת מטרות ודרכים
3. עורכת: מורידה יעד, משנה דרכים, או מוסיפה מטרת-על ידנית
```

אחרי המיפוי אפשר גם לבחור ידנית (תחום → מטרה → יעדים), למי שמכירה את השפה.

המטרה נכנסת לדוח אוטומטית אחרי שנבחר יעד אחד לפחות.  
ההערכה המילולית שייכת ליעד בקטלוג — לא שדה חופשי.

## מה נשמר בטופס (בחירות, לא טקסט)

| id | סוג | מה זה |
|---|---|---|
| `seen[]` | סימון | מזהי תצפית כיתה; לא נכנסים לפלט |
| `goals[].goalId` | בחירה מהקטלוג | מזהה המטרה |
| `goals[].timeframe` | `select` | פרק זמן להשגה: שנתי / חצי שנה / מחצית א' / מחצית ב'. ברירת מחדל: שנתי |
| `goals[].objectives[].objectiveId` | סימון | מזהה היעד |
| `goals[].objectives[].methodIds[]` | סימון | מזהי הדרכים של **אותו** יעד |

אסור לבחור דרך של יעד אחר. הדרכים מוצמדות ליעד.

## מגדר

כל פריט בקטלוג יש לו `text_m` ו-`text_f`.  
הפלט בוחר לפי `studentGender`. המורה רואה תצוגה מקדימה לפי המין שנבחר.

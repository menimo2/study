# לוגיקת ייצור — תל"א

[[דוח תל"א|← חזרה לדוח]] · [[תבנית פלט של תל"א]]

לחיצה על `מלא תל"א` ממפה `seen[]` ליעדים לפי [[תצפיות כיתה של תל"א]], ממלאת את הטופס (כל הדרכים של כל יעד), ומציגה לעריכה.

לחיצה על `צור תל"א` מייצרת **טבלאות** מהטופס המעודכן (אחרי עריכה), לא ישירות מהתצפיות.

## אנונימיזציה

```
nameDisplay = "***"
```

שם אמיתי לא נכנס לפלט.

## ברירות מחדל אם ריק

| שדה | אם ריק |
|---|---|
| `studentClass` | `---` |
| `schoolYear` | לא מדפיסים בשורת הכותרת |
| `goals[].timeframe` | `שנתי` |

## מגדר

המעטפת לפי מין (`שם התלמיד` / `שם התלמידה`).  
גוף הדוח: לכל `id` שנבחר, לוקחים `text_m` או `text_f` מהקטלוג.

תווית התחום בשורת המטרה:

| ערך | בטבלה |
|---|---|
| `academic` | לימודית |
| `emotional` | רגשית / התנהגותית |
| `social` | חברתית / התנהגותית |
| `behavioral` | התנהגותית |

## הרכבה מקטלוג

לכל בחירה בטופס:

1. `goalId` → נוסח המטרה; נכנס לשורה הראשונה של הטבלה
2. לכל `objectiveId` מסומן → נוסח היעד בעמודת **יעדים**
3. לכל `methodId` מסומן תחת אותו יעד → נוסח הדרך בעמודת **אופן הביצוע / אחריות**
4. דרך שלא שייכת ליעד שנבחר — נזרקת

## סינון

- מטרה בלי אף יעד מסומן — לא נכנסת לפלט.
- יעד מסומן בלי דרכים — נכנס; עמודת הביצוע ריקה.

## סדר בפלט

1. כותרת: תוכנית חינוכית יחידנית + פרטים אנונימיים
2. לכל מטרה שנשארה, לפי סדר הבחירה בטופס: טבלה + שורת פרק זמן
3. שורת חתימות

# עורך מאגר תל"א

[[דוח תל"א|← חזרה לדוח]] · [[קטלוג תל"א]] · [[איך להוסיף יעד לתל"א]]

קובץ: `TLA-bank.html`

כאן בודקים את המאגר בלי לגעת בקוד: משנים ניסוחים, מוסיפים מטרות / יעדים / דרכים / תצפיות, ומייצאים קובץ.

## איך עובדים

1. פותחים את `TLA-bank.html` בדפדפן.
2. בלשונית **מטרות ויעדים** — עורכים תווית, נוסח בן/בת, הערכה, ודרכים.
3. בלשונית **תצפיות כיתה** — עורכים מה שרואים בכיתה, ומסמנים לאילו יעדים זה ממפה.
4. לוחצים **ייצא קובץ**. נוצר `TLA-bank-export.json`.
5. שולחים את הקובץ בחזרה. משם מעדכנים את `TLA.html` ואת קבצי הקטלוג.

הדפדפן שומר טיוטה מקומית. **חזור למקור** מוחק אותה.

## פורמט הייצוא

```json
{
  "kind": "tla-bank",
  "version": 1,
  "exportedAt": "…",
  "domains": [],
  "catalog": [],
  "see": []
}
```

רק קובץ עם `kind: "tla-bank"` מתקבל בייבוא ובעדכון המחולל.

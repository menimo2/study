# ממשק — תל"א

[[דוח תל"א|← חזרה לדוח]] · [[תשתית]]

אותה שפה עיצובית כמו [[ממשק של דוח חינוכי-תפקודי]]: RTL, `#2c3e50` / `#3498db`, כרטיסיות, רוחב `950px`.

אין מקרא ירוק/אדום. הסימון הראשי הוא תצפיות כיתה (כן / לא).  
אחרי המיפוי — עריכה מתוך הקטלוג.

## מבנה העמוד

1. כותרת + הסבר: מסמנים מה שרואים, והתל"א מתמלאת
2. כרטיסייה: פרטים
3. כרטיסייה: **מה אני רואה בכיתה** — קבוצות לפי מקום/זמן, לא לפי תחום מקצועי
4. כפתור `מלא תל"א לפי מה שסימנתי`
5. כרטיסי התוכנית שנבנתה (ניתנים לעריכה) — היררכיה ויזואלית:
   - כל כרטיס צבעוני = **מטרה** (שם המטרה + המשפט המלא + תחום + פרק זמן)
   - בתוך הכרטיס: **יעדים בתוכנית** (ממוספרים, מסגרת בצבע המטרה). תחת כל יעד מסומן: **אופן הביצוע** ברצועה ירוקה
   - מתחת: **יעדים נוספים באותה מטרה** (מעומעמים) — לחיצה מוסיפה לתוכנית
   - צבע הכרטיס לפי תחום: חברתי כחול, התנהגותי כתום, רגשי סגול, לימודי ירוק-כחלחל
6. כפתור `צור תל"א` — פלט בטבלאות (מטרה, יעדים, אופן הביצוע) כמו בבית הספר
7. אזור פלט: העתק / הורד

## למה זה קל למורה

היא מתארת **התנהגות בכיתה**, לא אבחנה:

**מה שרואים → המערכת ממלאת מטרות / יעדים / דרכים → עורכים**

אין צורך לדעת אם זה «רגשי» או «חברתי». התחום מופיע רק בפלט, אחרי שהמערכת מיפתה.

ברגע שנבחר יעד (אוטומטית או ידנית), הדרכים **שלו** נפתחות מתחתיו, ומסומנות כולן כברירת מחדל (אפשר להוריד סימון).

מטרת-על שכבר נבחרה בכרטיס אחר לא תופיע שוב לבחירה.

לחיצה חוזרת על `מלא תל"א` מחליפה את מה שנבנה אוטומטית. אם כבר יש כרטיסים — שואלים אישור.

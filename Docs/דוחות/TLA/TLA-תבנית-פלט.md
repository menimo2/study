# תבנית פלט — תל"א

[[דוח תל"א|← חזרה לדוח]] · [[לוגיקת ייצור של תל"א]]

המסמך המודפס הוא **תוכנית חינוכית יחידנית**, בטבלאות כמו בבית הספר.  
כל מטרה = טבלה נפרדת.

כותרת המסמך:

```
תוכנית חינוכית יחידנית {שנת לימודים}
{שם התלמיד / שם התלמידה}: *** | כיתה: {כיתה}
```

אין פסקת פתיחה. ישר לטבלאות.

## טבלה לכל מטרה

שורה 1 (מאוחדת לשתי עמודות):

```
מטרה {לימודית / רגשית / התנהגותית / חברתית / התנהגותית} — {נוסח המטרה}
```

שורה 2 (כותרות עמודות):

| יעדים | אופן הביצוע / אחריות |
|---|---|

שורות הבאות: יעד אחד בכל שורה, מול הדרכים שלו (כל דרך בשורה חדשה עם נקודה).

מתחת לטבלה:

```
פרק זמן להשגה: {שנתי / חצי שנה / מחצית…}
```

אחרי כל הטבלאות:

```
חתימת המחנך/ת: __________     חתימת ההורים: __________     תאריך: __________
```

## מה לא מודפס

- התצפיות שסומנו בטופס
- שם התלמיד/ה (תמיד `***`)
- עמודת הערכה — בדוגמאות בית הספר אין אותה; ההערכה נשארת בקטלוג ולא נכנסת לטבלה

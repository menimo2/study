# תוכנית לימודים אישית (תל"א)

[[קטלוג דוחות|← קטלוג דוחות]] · [[README|בית]]

מחולל תוכנית קדימה: מה הצוות מתכנן עם התלמיד/ה.  
לא דוח סיכום של מה שכבר קרה — רק הצגת התוכנית.

המונחים בפלט הם של בית הספר: **מטרה**, **יעדים**, **אופן הביצוע / אחריות**, **פרק זמן להשגה**.  
המסמך המודפס נקרא **תוכנית חינוכית יחידנית**. הכלי בממשק נשאר «מחולל תל"א».

| | |
|---|---|
| מזהה | `tla` |
| כותרת בממשק | מחולל תל"א (תוכנית לימודים אישית) |
| תת-כותרת | מסמנים מה שרואים בכיתה — והתל"א מתמלאת (אנונימי) |
| קהל | מחנכות, צוות חינוך מיוחד, צוות שילוב |
| שפה | עברית, RTL |
| מצב | ניסוי — אב-טיפוס HTML |
| אב-טיפוס | `TLA.html` |

## היררכיה

```
תחום (לימודי / רגשי / חברתי / התנהגותי)
  └── מטרה     ← שורה ראשונה בטבלה
        └── יעד אחד או יותר   ← עמודה ימנית
              └── אופן הביצוע / אחריות   ← עמודה שמאלית (הדרכים של היעד)
```

- **מטרה** — לאן רוצים להגיע. רחבה יחסית. טבלה אחת לכל מטרה.
- **יעד** — נגזר מהמטרה. יישומי, אפשר לראות אותו בכיתה.
- **אופן הביצוע / אחריות** — שייך ליעד. המורה בוחרת מתוך רשימת הדרכים המקושרת.
- **פרק זמן להשגה** — לכל מטרה (ברירת מחדל: שנתי).

ההערכה המילולית נשמרת בקטלוג ולא מודפסת בטבלה (כך בנויות דוגמאות בית הספר).

כניסת המורה לטופס:

```
תצפית כיתה (מה שרואים)
  └── מיפוי אוטומטי
        └── מטרה + יעדים + דרכים  ← המורה עורכת
```

המורה **לא בוחרת תחום**. היא מסמנת תצפיות כיתה מתוך [[תצפיות כיתה של תל"א]].  
המערכת ממפה ליעדים ב[[קטלוג תל"א]], ממלאת מטרות ודרכים, והמורה עורכת.

אין כתיבת מלל — רק סימון ואז עריכה.

# תשתית דוחות

[[README|← חזרה לבית]] · [[קטלוג דוחות]] · [[איך לבנות כלי]] · [[איך להוסיף דוח]]

כל סוגי הדוחות בפרויקט חולקים את אותם כללי יסוד.  
דוח חדש **לא ממציא מנגנון חדש** — הוא רק ממלא תוכן לפי החוזה הזה.

## 1. שפה וכיוון

- ממשק מלא בעברית.
- כיוון RTL.
- בחירת מין (זכר / נקבה) משפיעה על **כל** הניסוחים בממשק ובדוח הסופי.

## 2. סוגי שדות

כל שדה בדוח חייב להיות אחד מהסוגים הבאים:

| סוג | תיאור | דוגמה |
|---|---|---|
| `text` | שורת טקסט חופשית | שם, כיתה, תאריך אבחון כטקסט |
| `date` | בחירת תאריך | תאריך לידה, תאריך כתיבת הדוח |
| `select` | בחירה מרשימה סגורה | מין, מסגרת לימוד |
| `textarea` | טקסט ארוך | הערות, המלצות |
| `toggle` | לחצן דירוג תלת-מצבי | חוזקה / קושי / לא רלוונטי |
| `repeater` | קבוצה שחוזרת (אפשר להוסיף/להסיר) | מטרות בתל"א, יעדים תחת מטרה |

לכל שדה חייבים להיות:

- `id` — מזהה יציב באנגלית (לשימוש בקוד)
- `label` — תווית בעברית (לממשק)
- `type` — אחד מהסוגים למעלה
- `required` — כן / לא
- `anonymize` — כן / לא (רק לפרטים מזהים)
- `placeholder` — אם רלוונטי
- `options` — אם זה `select`
- ניסוחי מגדר — אם זה `toggle`
- `item_fields` — אם זה `repeater`: רשימת השדות בכל פריט. מותר repeater בתוך repeater (למשל יעדים בתוך מטרה).

## 3. לחצן Toggle — חוזה תלת-מצבי

זה המנגנון המרכזי של התשתית. כל דוח שמשתמש ב-toggle חייב לממש אותו כך:

| מצב | ערך נתונים | צבע בממשק | מה קורה בדוח |
|---|---|---|---|
| ניטרלי | `null` | אפור `#dcdfe6` | **לא נכנס לדוח בכלל** |
| חיובי | `v` | ירוק `#27ae60` | נכנס ניסוח `pos` לפי מין |
| שלילי | `x` | אדום `#e74c3c` | נכנס ניסוח `neg` לפי מין |

### מחזור לחיצה

`null` → `v` → `x` → `null`

לחיצה אחת עוברת למצב הבא. אין בחירה נפרדת של ירוק/אדום — זה אותו לחצן.

### ארבעה ניסוחים לכל לחצן

כל toggle חייב לכלול את ארבעת הניסוחים במלואם. אין קיצורי דרך של "בנקבה לשנות את הסוף":

| מפתח | מתי משתמשים |
|---|---|
| `pos_m` | מצב ירוק + זכר |
| `pos_f` | מצב ירוק + נקבה |
| `neg_m` | מצב אדום + זכר |
| `neg_f` | מצב אדום + נקבה |

### תצוגה מקדימה בלחצן

כשהמצב אינו ניטרלי, מתחת לתווית מופיע המשפט שייכנס לדוח, מותאם למין שנבחר כרגע.  
שינוי המין מעדכן מיד את כל התצוגות המקדימות.

### משמעות ירוק/אדום לפי הקשר

המנגנון זהה, המשמעות משתנה לפי הקבוצה:

- בתחומי תפקוד (לימודי, רגשי, חברתי): ירוק = חוזקה, אדום = קושי.
- באבחנות: ירוק = האבחנה קיימת, אדום = ללא האבחנה.
- בסל תמיכות: ירוק = מקבל את המענה, אדום = אינו מקבל.

בכל מקרה — מצב ניטרלי לא נכנס לדוח.

## 4. מגדר

שדה המין הוא שדה-על של כל דוח.

- ערכים: `male` | `female`
- תוויות בממשק: `זכר (בן)` | `נקבה (בת)`
- ברירת מחדל: `male`

כל מחרוזת שמופיעה בדוח או בתצוגה מקדימה חייבת להיבחר לפי המין.  
אין להשאיר בממשק או בפלט צורות כמו `לומד/ת` אם המין כבר ידוע — **אלא אם המפרט של הדוח הספציפי אומר במפורש אחרת**.

## 5. פרטיות (Privacy Guard)

שדות שמסומנים `anonymize: true`:

- נשמרים בטופס כדי שהמורה תוכל למלא אותם.
- **בפלט הדוח מוחלפים תמיד ב-`***`**.
- אסור להדפיס אותם, לשמור אותם בקובץ מורד, או לשלוח אותם ל-AI.

כרגע השדות האנונימיים הם: שם התלמיד/ה, תעודת זהות.

## 6. בניית פלט

כל דוח מגדיר:

1. אילו שדות נכנסים לאיזה פרק.
2. אילו toggles נכנסים כרשימת חוזקות, ואילו כרשימת קשיים.
3. מה קורה אם קבוצה ריקה (לא נבחר אף לחצן) — בדרך כלל מדלגים על המשפט.
4. תבנית טקסט סופית להעתקה.

פירוט לכל דוח נמצא בקבצי `לוגיקת ייצור` ו-`תבנית פלט` שלו.

## 7. ממשק משותף

כל כלי שנבנה מהתשתית הזו צריך לכלול:

- כותרת הדוח + הסבר קצר
- מקרא צבעים (אפור / ירוק / אדום)
- כרטיסיות לפי פרקי הדוח
- רשת לחצני toggle
- כפתור "צור דוח"
- אזור תצוגת פלט (מוסתר עד ליצירה)
- כפתור העתקה ללוח

צבעים בסיסיים:

| תפקיד | ערך |
|---|---|
| רקע עמוד | `#f4f6f9` |
| כרטיס | `#ffffff` |
| כותרת / primary | `#2c3e50` |
| כפתור / secondary | `#3498db` |
| ירוק | `#27ae60` |
| אדום | `#e74c3c` |
| מסגרת | `#dcdfe6` |

פרטי עיצוב של דוח ספציפי נמצאים בקובץ הממשק שלו.

## 8. מה לא נמצא כאן

תוכן השאלות, הניסוחים, וסדר הפרקים — אלה שייכים לדוח הספציפי.

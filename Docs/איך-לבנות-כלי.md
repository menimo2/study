# איך לבנות כלי מתוך ה-MD

[[README|← חזרה לבית]] · [[תשתית]] · [[קטלוג דוחות]]

המסמכים האלה מספיקים כדי לבנות את הכלי בלי להסתכל על שום קובץ קוד.

## סדר עבודה

1. קראו את [[תשתית]] — זה החוזה המשותף.
2. בחרו דוח מתוך [[קטלוג דוחות]].
3. קראו את דף ההוב של הדוח (למשל [[דוח חינוכי-תפקודי]]).
4. ממשו את השדות לפי קבצי הפרקים (`01` עד `06`).
5. ממשו את הממשק לפי קובץ הממשק של הדוח.
6. ממשו את יצירת הטקסט לפי `לוגיקת ייצור` + `תבנית פלט`.

## מה חייב להיות בקוד

הקוד הוא מנוע, לא מקור תוכן.

- רכיב טופס לפי סוגי השדות מ-[[תשתית]].
- רכיב toggle תלת-מצבי עם ארבעה ניסוחים.
- רכיב checkbox עם שני ניסוחים (`text_m` / `text_f`).
- בחירת מין שמעדכנת תצוגות מקדימות.
- מנוע פלט שמחליף פרטים מזהים ב-`***` ומרכיב פסקאות לפי הכללים.
- כפתור העתקה.

הניסוחים עצמם לא אמורים להיות כתובים ידנית בקומפוננטות.  
ב-Next.js / אפליקציה: טענו אותם מנתונים (JSON / MD / CMS) שנגזרים מהמסמכים האלה.

## מה אסור

- להמציא שדות שלא מופיעים במפרט הדוח.
- לקצר ניסוחי מגדר ("פשוט נוסיף ת' בסוף").
- להכניס לדוח לחצן במצב ניטרלי.
- להדפיס שם או ת.ז. בפלט.

## בדיקת שלמות

אחרי בנייה, אפשר לבדוק שהכלי נאמן למסמכים אם:

- כל `id` מקבצי השדות קיים בממשק.
- לכל toggle יש בדיוק 4 ניסוחים.
- לכל checkbox יש בדיוק `text_m` ו-`text_f`.
- שינוי מין משנה תצוגה מקדימה וגם את הפלט.
- שם ות.ז. בפלט הם תמיד `***`.
- פלט הדוח תואם לתבנית הפלט של הדוח הרלוונטי.

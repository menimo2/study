# איך להוסיף סוג דוח חדש

[[README|← חזרה לבית]] · [[תשתית]] · [[קטלוג דוחות]]

התשתית בנויה כך שדוח חדש הוא תיקייה + קישורים, לא שכתוב של המערכת.

## שלבים

1. הוסיפו שורה ב-[[קטלוג דוחות]].
2. צרו דף הוב לדוח, באותו מבנה כמו [[דוח חינוכי-תפקודי]].
3. צרו תיקייה בשם האנגלי היציב של הדוח (למשל `SocialReport`).
4. בתוך התיקייה צרו לפחות:

   - `{מזהה}-ממשק.md` — מסכים, כפתורים, עיצוב ייחודי
   - `{מזהה}-לוגיקת-ייצור.md` — איך מרכיבים את הטקסט
   - `{מזהה}-תבנית-פלט.md` — איך נראה הדוח הסופי
   - קובץ אחד לכל פרק שדות (`{מזהה}-01-...`)

   קידומת המזהה (למשל `FE-`) חשובה ל-Obsidian: שמות הקבצים חייבים להיות ייחודיים בכל ה-vault, לא רק בתוך התיקייה.

5. בכל קובץ שדות השתמשו בחוזה מ-[[תשתית]]:
   - `id`, `label`, `type`, `required`, `anonymize`
   - ל-toggle: `pos_m`, `pos_f`, `neg_m`, `neg_f`
   - ל-checkbox: `text_m`, `text_f`
6. קשרו הכל ב-wikilinks כדי שהעץ ב-Obsidian יישאר קריא.

## מה לחזור עליו ומה לא

| לחזור (מהתשתית) | לא להמציא מחדש |
|---|---|
| Toggle תלת-מצבי | מנגנון לחיצה אחר |
| Checkbox כן/לא | דירוג חדש בלי סיבה |
| מגדר בזמן אמת | ניסוח ידני לכל מקרה |
| הסתרת שם ות.ז. | כללי פרטיות שונים בלי סיבה |
| כרטיסיות + מקרא צבעים | |

מותר לדוח חדש להוסיף סוגי שדות, בתנאי שמעדכנים גם את [[תשתית]].

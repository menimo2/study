# תכנת דוחות חינוכיים

זה **מקור האמת** של הפרויקט.

התכנה הזו היא תשתית לבניית מחוללי דוחות. אפשר לבנות ממנה דף HTML, אתר Next.js, אפליקציה, או כל כלי אחר — בכל טכנולוגיה — כי **כל המידע נמצא בקבצי ה-Markdown**, לא בקוד.

> קובץ ה-HTML הקיים (`FunctionalEducational.html`) הוא אב-טיפוס בלבד.  
> אם יש סתירה בין הקוד לבין המסמכים האלה — **המסמכים מנצחים**.

## איך לקרוא את זה ב-Obsidian

1. פתחו את תיקיית הפרויקט כ-Vault.
2. התחילו מכאן (הדף הזה).
3. לחצו על קישורים מסוג `[[שם הפתק]]` כדי לעבור בין הדפים.
4. גרף הקשרים ב-Obsidian אמור להראות: **בית → קטלוג דוחות → דוח ספציפי → שדות / ממשק / לוגיקה**.

מומלץ להפעיל תצוגת RTL בהגדרות Obsidian.

## עיקרון אחד

כל סוג דוח הוא **נתונים + כללים**, לא קוד.

- השדות, הניסוחים, המגדר, מבנה הפלט והממשק חיים ב-MD.
- הקוד רק מציג את הנתונים ומריץ את הכללים.
- לכן אפשר להחליף טכנולוגיה בלי לאבד את המוצר.
